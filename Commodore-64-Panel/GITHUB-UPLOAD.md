# Upload to GitHub

Suggested repository name: `ha-commodore64-panel`.

1. Extract the release ZIP and open the folder containing `README.md`.
2. In your GitHub repository, choose **Add file → Upload files**.
3. Upload the contents of this folder, keeping `www`, `themes`, `docs`, and `screenshots` intact. Place `README.md` at the repository root, not inside another package folder.
4. Commit the upload. GitHub will display the screenshots within the README using relative links.
5. Optionally create a release and attach the ZIP for easy downloading.

If updating an existing repository, preserve your chosen licence and review the changes before replacing your README. Do not upload a private game collection or Home Assistant secrets. `.gitignore` helps with Git clients, but does not prevent accidental uploads through the website.

Repository description suggestion: Commodore 64-inspired Home Assistant dashboard with themed controls, optional camera review and browser minigames.
