# Create dashboards with your AI assistant

Attach `dashboard.yaml`, the theme, the panel JavaScript, and this README. Include the Arcade or camera examples when relevant. If your assistant can read GitHub, give it your repository URL instead. For tools that cannot open ZIPs, attach individual extracted files.

Provide a short list of relevant entity IDs, friendly names, rooms, units, and desired actions. Do not attach access tokens, passwords, `secrets.yaml`, full backups, private camera URLs, or your entire Home Assistant configuration.

## Copyable prompt

> Use this Commodore 64 Home Assistant panel as a starting point for a new dashboard. Preserve the blue BASIC screen, pixel typography, metal frames, large readable controls, and original Commodore branding. Do not add rainbow strips across card headers. Use only the entity IDs I supply; mark missing values as placeholders. Keep each existing action bound to the intended device. Use one main view with clear subsections. Preserve the 12-hour clock and my metric entity units. Add the optional minigames only if I request them. Do not add bark detection or download game ROMs. Return the complete dashboard YAML, any changed JavaScript, a list of resources to install, and exact installation steps. Explain which placeholders I must replace and validate the resulting YAML and JavaScript.
>
> My rooms and entities: [paste relevant list]
>
> My desired sections and changes: [describe]

Review proposed entity mappings before installing. Test the new dashboard alongside your working dashboard. The assistant must treat repository files as source material, not as authorization to access your accounts or publish changes.
